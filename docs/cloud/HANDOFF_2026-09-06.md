## 5. 必须知道的发现（否则会走错方向）

完整版在 `docs/cloud/IMPLEMENTATION_NOTES.md` §1.6，这里只列结论：

1. **Desktop 现在不经 gRPC 做 Nest。** `MainWindow.xaml.cs` 的 `RunNestAsync`（约 L5266–5597）在进程内直接调 `NestEngineRouter`，输入是完整 `Panel` 多边形 + 多张余料 `NestSheetSpec` + 引擎偏好（默认 `nfp`）+ 进度 + 锁定摆位 + parts-in-part。`WorkerProcessHost` 只用来做健康自检。
2. `ComputeWorker/Services/NestingServiceImpl.cs` 是一条独立的**矩形 AABB** Nest 路径，字段恰好等于 spec §9 的云端契约。Task 2 就是把它的编排搬进 `NestingRunner`，算法（`NestEngineRouter` / `GroupedBlfNester` / `NestValidator`）原样复用，不重写。
3. Task 9 接 Desktop 时，Intranet 模式的输入要先降成矩形契约（AABB + 单一 stock 规格）。这和 Desktop 进程内 NFP 路径不等价——**要在文档和验收里写明差异，不能装作一样**。Local/Server parity 应比较“同一个 `INestingRunner` 在本地 gRPC worker 与云端 worker 的输出”。
4. `.gitignore` 有 `.env.*` → Task 8 提交 `deploy/intranet/.env.example` 要加 `!deploy/intranet/.env.example`。
5. `CabinetNC.Desktop.csproj` 的 `CopyWorker` target 会把 ComputeWorker 复制进 Desktop 输出和 `dist/CabinetNC-Cut`；Task 12 customer build 必须能排除。
6. 测试栈：xunit 2.9.3 / Microsoft.NET.Test.Sdk 17.14.1 / coverlet 6.0.4，`<Using Include="Xunit" />`。解决方案是 `dotnet/CabinetNC.slnx`（XML）。
7. CI 两个 workflow 都是按项目逐个 `dotnet test`，新增测试项目要手动加进 `.github/workflows/regression.yml` 和 `windows-desktop.yml`。
8. 本机没有 `pwsh` 7，只有 Windows PowerShell 5.1；smoke 脚本兼容 5.1。
9. GitHub 权限 pull-only。要推送先 fork：`gh repo fork yzhan722/cabinetnc-cut --clone=false` 然后 `git remote add fork <url>` / `git push -u fork feature/intranet-cloud-poc`。

接口（照计划原文）：

```csharp
public sealed record NestingPartInput(string PanelId,double WidthMm,double HeightMm,bool MayRotate,string? Material,double ThicknessMm);
public sealed record NestingInput(IReadOnlyList<NestingPartInput> Parts,double SheetWidthMm,double SheetLengthMm,double SpacingMm,double BorderMm,bool AllowRotation);
public sealed record NestingPlacementOutput(string PanelId,int SheetIndex,double OffsetX,double OffsetY,double RotationDeg);
public sealed record NestingWarningOutput(string Code,string Message,string? PanelIdA,string? PanelIdB,int? SheetIndex);
public sealed record NestingOutput(bool Ok,string Engine,IReadOnlyList<NestingPlacementOutput> Placements,int SheetCount,IReadOnlyList<string> Unplaced,IReadOnlyList<NestingWarningOutput> Warnings,string? Error);
public interface INestingRunner { NestingOutput Run(NestingInput input); }
```

先写这 5 个测试再实现：`Run_places_two_rectangles_without_overlap`、`Run_honors_no_rotation_part`、`Run_returns_unplaced_for_oversized_part`、`Run_preserves_material_and_thickness_behavior`、`Run_is_deterministic_for_same_input`。
