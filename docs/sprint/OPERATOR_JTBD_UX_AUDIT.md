**Persona**：Troy 车间的机床操作员。一个人同时管 OmniCam、OSAI 控制器、贴标软件和板材。
英文母语、看得懂常用中文界面词但不读长句；工作时戴手套、站着、显示器离眼睛一米。
最怕的不是功能少，而是"软件说好了、机床卡住了"（2026-08-19 那种）。

来源：八月 14 个功能提交的说明（每条都是一个车间故事）、贴标事故交接、`MainWindow.xaml.cs` 的 147 条状态栏文案和 16 处弹窗。

## UX 走查发现（按严重度）与 2026-09-02 改版处理状态

### 会导致停机或错件

1. **导出成功 ≠ 可以上机。** 状态栏一行字承载了"文件写在哪、标签几张、拷到哪、缺哪些"。缺 BMP 这种会让机床卡死的信息
   不应该和"已导出"并列在一行灰字里。
   → **已处理**：每次导出后弹出非阻塞通知卡；缺 BMP 时为红色错误卡（12 秒），正常时为绿色卡，均带"打开目录"按钮；状态栏按严重度着色。
   缺 BMP 是否改为阻断导出仍待 Troy 拍板（`LABELING_REQUIREMENTS.md` L3）。
2. **两套后置在界面上没有区分。** → **已处理**：导出页每个文件卡片第一行标明"OSAI 单文件 .anc · Z0=板底 · 自动换刀 M6 · 安全高 30"；右栏说明也写明后置类型。
3. **预检"仍要继续导出吗？"** 是一个 Yes/No 弹窗。→ **已处理**：改为 `OverrideReasonWindow`，列出全部问题，必须填写 ≥ 6 字原因才能继续，原因写入 `UsageLog`（`export.preflight.override`）。

### 让人不信任软件

4. **中英文混排。** → **已处理**：153 条状态文案中纯英文降为 0；`Worker: DOWN` 之类的技术告警改为中性的"计算引擎 · 本地"，只在主动自检时报告。
   资源文件化仍未做（`DESKTOP_TESTABILITY_PLAN.md` 全局项）。
5. **弹窗承载业务规则。** → **未处理**（需要把余料规则做成库设置项，属于功能改动）。
6. **"作废"语义不统一。** → **已处理**：几何修改后，阶段栏下方出现黄色横幅"板件已修改…"并带「重新密排」按钮；顶部五个步骤标签中密排/刀路/导出同时变为 ⚠ 黄色。

### 效率

7. **三个高频动作三种手势。** → **未处理**（需要逐卡片加 `…` 菜单）。
8. **库设置分散。** → **部分处理**：「参数设置」新增"机床与贴标"卡片，机床标签图片目录可编辑（关闭 L1）；后置数值仍在代码常量。
9. **反推结果无对照。** → **未处理**。

### 本次改版额外解决的问题（走查时未列出，截图基线中发现）

- 没有设计系统：颜色/字号/间距散落在 1 300 行 XAML 里，按钮全部是默认外观、无主次。→ 新建 `Theme.xaml`（令牌 + 按钮四级/输入框/列表/滚动条/卡片/工具提示），每一步只有一个深色主操作（打开方案 → 初始密排 → 重新密排 → 计算全部 → 导出全部 / 一键导出）。
- 顶栏 7 个同级按钮含开发工具。→ 按"方案 | 工程 | 更多▾"分组，`使用日志`/`Ping`/快捷键进"更多"菜单；模块导航加图标与激活指示条。
- 阶段 4/5 在前置未完成时是空白画布。→ 新增"刀路需要先有密排 → 前往密排"、"还没有可导出的刀路 → 前往刀路/密排"引导态。
- 五个无标签的圆点。→ 可点击的步骤标签（✓ 完成 / • 待做 / ⚠ 作废），悬停有说明。
- 密排完成后按钮仍禁用、进度条满格数秒。→ 根因是 `RunNestAsync` 在忙碌态内 `await` Worker 预热，已移到忙碌态释放之后；进度回调加 `_nestBusy` 守卫。
- 启动时"先载入方案"状态会在数秒后覆盖用户的操作结果。→ 状态先写，Worker 探测最后做。
- 密排/刀路完成有绿色通知卡并可一键跳到下一步；快捷键 Ctrl+O / Ctrl+Shift+O / Ctrl+S / Ctrl+E / Ctrl+1…5。
- 复合内容按钮补充 `AutomationProperties.Name`，UI 自动化与读屏可继续按名称定位。

## 第二轮：对照成熟 CAD/CAM 软件的行业惯例（2026-09-03）

参照 Fusion 360 / Mastercam / VCarve / Alphacam 这类工业软件里"用户默认期待存在"的交互，逐项对照 OmniCam：

| 行业惯例 | 改版前 | 现在 |
|---|---|---|
| 视口随时可缩放/平移（滚轮对准指针缩放、中键平移、适配键） | 只有导出页能缩放，密排和刀路页固定适配 | 三个阶段共用一套视口变换；滚轮/中键/`F`/`Home`/`+`/`−`；底部居中导航条（− 缩放% + 适配）；换大板或重新密排自动适配 |
| 光标坐标与缩放比例常驻状态栏 | 无 | 状态栏右侧 `X 123.4 Y 56.7 mm · 缩放 156%`（原点=大板左下角） |
| 仿真传输控制：首/上一段/播放/下一段/尾 | 只有播放与滑块 | 五键传输条 + 空格播放/暂停 |
| DRO 读数（当前 X/Y/Z、刀号/直径、进给、块号） | 只有 T/Z/F | `X 717.0 Y 25.0 Z 30.00 T1 Ø6.35 快移 10/153` |
| 后台绘图与代码双向联动 | 无 | 仿真时代码区高亮当前块并自动滚动到上三分之一；点任意代码行把仿真定位到该运动块（Domain 侧给 `OsaiLine`/`ToolStroke` 增加了源码行号） |
| 完整菜单栏，每项标注快捷键 | 无菜单栏 | 文件/编辑/视图/密排/刀路/导出/帮助，全部命令可发现，快捷键随项显示 |
| 数值框回车应用、Esc 离开 | 只能失焦应用 | 全局 Enter=应用（触发既有 LostFocus 提交）、Esc=离开 |
| 关于对话框含版本与提交 SHA | 无 | 帮助 → 关于：版本、`commit <sha>`（SDK 构建时嵌入）、构建时间、运行时、机型、库路径，一键复制——`SHOP_LOG.md` 需要的 SHA 从这里来 |
| 步骤/模块带图标 | 纯文字 | 阶段标签与模块栏图标；图标按钮均带 `AutomationProperties.Name` |

### 第二轮补充（同日稍后）

| 行业惯例 | 现在 |
|---|---|
| 未保存变更模型：标题栏/状态栏 `*`，关闭与打开另一文件前提示 保存/放弃/取消 | 用"可保存内容指纹"实现：包 JSON + 摆位 + CAM 会话（剔除阶段、当前大板、选中文件等纯视图状态）+ 工程名 + 机型 做 SHA-256，打开/保存时记基线。改几何、密排、算刀路、改工程名都会点亮 `*`；切换页签不会 |
| 最近打开 | `library.json` 记录最近 10 个（方案 / 工程 / .anc），文件 → 最近打开 子菜单，空状态页也列出最近 5 个可直接点开；不存在的文件灰显并在点击时自动移除 |
| 长计算可取消 | 密排进行中状态栏出现「取消」，通过已有的 `CancellationToken` 停止引擎，保留上一次结果 |
| 卡片动作有可见入口 | 板件分组头右侧 `⋯` 按钮打开菜单：板材页是「重命名种类…」，其他页是「移出这份方案…」；右键与双击仍可用 |

### 第三轮补充（2026-09-03）

| 项目 | 现在 |
|---|---|
| 图层/显示开关（J3） | 画布工具栏「显示 ▾」：板件纹理、孔/槽/口袋特征、标签锚点、选中板件尺寸标注、仿真快移线；密排页与导出页共用一个菜单实例，状态同步 |

## 建议的验证方式（不需要机床）

- 每个 Job 写成一条 `MANUAL_SMOKE_10MIN.md` 用例，步骤 ≤ 8 步，每步一句预期。
- 让一个没参与开发的人（不是 Troy）按用例操作一遍并录屏，记录每次"停下来想"的位置。这些位置就是下一轮 UX 修改的清单。
- 文案问题用一个 `strings` 审计脚本锁住：状态栏与弹窗文案全部收敛到一个文件后，CI 检查没有新的内联字符串。
