# Intranet compute mode end to end: sign in → nest (nest.v2) → CAM (operations job) → NC (post job) → export.
# Needs a running API; run-all.ps1 skips this scenario unless CABINETNC_SMOKE_API_URL is set:
#   CABINETNC_SMOKE_API_URL   e.g. http://127.0.0.1:8080 (loopback http) or https://cabinetnc.shop.local
#   CABINETNC_SMOKE_TENANT / CABINETNC_SMOKE_EMAIL / CABINETNC_SMOKE_PASSWORD
# The private library dir set by run-all.ps1 also isolates cloud.json / cloud.token from the operator's.
